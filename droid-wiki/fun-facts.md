# Fun facts

Oddities and curiosities found in the Corvex Console repository. Each one is verifiable with a single command.

## 1. The whole app was committed in about 9 minutes

The repository has 18 commits, and every timestamp falls between 22:18:44 and 22:27:52 -04:00 on 2026-09-21. Scaffold, seven features, tests, CI, deployment config, docs, and a refactor: roughly 9 minutes, about 30 seconds per commit. Every single commit also carries a `Co-authored-by: factory-droid[bot]` trailer — 18 out of 18 — making this a fully AI-orchestrated burst under one human author's name. See [Lore](lore.md) for the full timeline.

## 2. The repository is from the future (or the changelog is wrong)

Git insists the project was built on **2026-09-21**. `CHANGELOG.md` insists version **0.1.0 shipped on 2025-01-15**. The changelog therefore describes a release made more than a year before the first commit existed. One of the clocks is lying, and it is probably the changelog's fictional framing.

## 3. The demo never ages because time is frozen

"Last N days" filtering in the mock API is anchored to a hard-coded date in `src/mocks/handlers.ts:36`:

```ts
new Date("2024-12-31").getTime() - Number(range) * 86_400_000;
```

No matter when the demo runs, "the last 30 days" always ends on New Year's Eve 2024. The seeded data never drifts out of range, so screenshots and demos stay reproducible forever. More on the mock backend in [Mock API](../features/mock-api.md).

## 4. Reveal-once secrets that reveal nothing

The integrations page issues demo API keys whose secrets literally end in `_demo_secret_reveal_once` (`src/mocks/handlers.ts:68`). The "reveal once" ceremony is real — the UI shows the secret a single time — but the thing being protected is a string that announces itself as a demo secret. There is even a test asserting the reveal: `src/test/app.test.tsx:104` checks that the secret text contains `demo_secret_reveal_once`.

## 5. Remarkably flat for a full app

The largest hand-written file in the repository is `src/config/brand.ts` at **141 lines**, and no application page exceeds 137 lines (`src/pages/app/AssistantPage.tsx`). A marketing site, an authenticated console with six product pages, a mock API, and tests fit into about 2,100 lines of TypeScript/TSX with no file anyone would call big. The only larger file, `public/mockServiceWorker.js` (361 lines), is generated by MSW and not written by hand. Full breakdown in [By the numbers](by-the-numbers.md).
